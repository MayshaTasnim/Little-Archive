# Little Archive

Little Archive is a stationery e-commerce website developed as an academic project. The website allows users to browse stationery products such as notebooks, stickers, sticky notes, and washi tapes.

## Features

* Responsive homepage and navigation
* Product categories
* Product listings
* Product search
* Product details
* Add/remove products from favorites
* Favorites saved using LocalStorage
* Backend API for product data

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Node.js
* Express.js
* JSON
* LocalStorage

## How to Run Locally

1. Clone the repository.
2. Open the project folder in a terminal.
3. Go to the Backend folder:
bash
cd Backend

4. Install the required dependencies:
bash
npm install

5. Start the backend server:
bash
node server.js

6. Open the frontend through a local server and use the website.
